## Description

As part of our Python and data analytics upskilling, this group task focuses on solving a real-world data analysis problem by implementing the same operations using standard Python (without NumPy) and NumPy, then comparing both approaches.

The team must select a suitable scenario, prepare a relevant dataset, and implement multiple data processing and analytical operations using both approaches. The analysis should go beyond simple calculations and demonstrate how each approach handles data manipulation, aggregation, filtering, multidimensional arrays, and statistical operations.

Task Requirements

1. Scenario Selection: Choose a real-world problem that requires processing and analyzing numerical data.
2. Dataset Preparation: Collect or create a dataset relevant to the selected scenario.
3. Implementation Without NumPy: Use standard Python lists, loops, conditions, and built-in functions to perform the required operations.
4. Implementation With NumPy: Perform equivalent operations using NumPy arrays and its mathematical and statistical functions.
5. Comparative Analysis: Compare both implementations in terms of code complexity, readability, execution time, memory usage where measurable, and suitability for larger datasets.
6. Results and Interpretation: Verify that both approaches produce equivalent results and explain the findings.
7. Documentation: Prepare a project document containing the scenario, problem statement, dataset, libraries used, code implementations, outputs, comparison, and conclusion.
Expected Outcome

A complete group project demonstrating how a real-world data analysis problem can be solved using standard Python and NumPy, with executable code, verified results, and a comparison of both approaches.

## Description

1. pgrep – Find running processes by name and display their process IDs.
2. nice – Start a process with a specified scheduling priority.
3. renice – Change the scheduling priority of an existing process.
4. lsblk – List block devices, their sizes, filesystems, and mount points.
5. mount – View currently mounted filesystems and storage devices.
6. umask – View or configure default permissions for newly created files and directories.
7. getfacl – Inspect file and directory access control lists (ACLs).
8. namei – Inspect each component of a path and its associated permissions.
9. fuser – Identify processes using specific files, directories, or network ports.
10. lsattr – View special filesystem attributes associated with files and directories.

## Description

1. dig – Query DNS records and retrieve domain name resolution information.
2. nslookup – Look up DNS information for domains and IP addresses.
3. traceroute – Trace the network path packets take to reach a destination.
4. nc – Test TCP/UDP connectivity and check whether specific network ports are reachable.
5. whois – Retrieve domain registration and ownership information.
6. getent – Query system databases such as hosts, users, and groups using configured system lookup services.
7. nmap – Scan hosts and identify open network ports.
8. getconf – Retrieve system configuration values, runtime limits, and POSIX-related settings.
9. lspci – List PCI devices connected to the system, including GPUs, network controllers, and audio devices.
10. ip neigh — Inspect the ARP/neighbour table

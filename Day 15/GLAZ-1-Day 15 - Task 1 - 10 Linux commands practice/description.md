## Description

1. pstree – Display running processes in a hierarchical parent-child tree.
2. pidof – Retrieve the process ID of a running program.
3. jobs – List background and suspended jobs in the current shell session.
4. disown – Remove a background job from the shell's job table.
5. wait – Wait for background processes to complete before continuing execution.
6. ulimit – View or configure resource limits for the current shell and its child processes.
7. vmstat – Display virtual memory, CPU, process, and system I/O statistics.
8. iostat – Monitor CPU utilization and input/output statistics for storage devices.
9. last – Display recorded user login sessions and system reboot history.
10. groups – Display the group memberships of the current or specified user.

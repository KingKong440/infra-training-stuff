## Description

1. du – Analyze disk usage of files and directories.
2. stat – Display detailed file metadata, including permissions, ownership, size, and timestamps.
3. setfacl – Configure fine-grained file and directory access permissions using ACLs.
4. readlink – Read and resolve symbolic links.
5. findmnt – Display mounted filesystems and their mount points.
6. tune2fs – Inspect and modify ext2/ext3/ext4 filesystem parameters.
7. filefrag – Display file fragmentation information.
8. fallocate – Preallocate disk space for files.
9. truncate – Create or modify files to a specified size.
10. lsns – List Linux namespaces and their associated processes.

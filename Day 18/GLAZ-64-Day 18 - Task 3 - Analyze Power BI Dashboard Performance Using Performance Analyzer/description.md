## Description

Step 1: Open the Optimize Tab

- Open the completed Sales Performance Dashboard in Power BI Desktop.
- Navigate to the Optimize tab in the ribbon.
Step 2: Open Performance Analyzer

- Click on Performance Analyzer.
- The Performance Analyzer pane will appear on the screen.
Step 3: Start Recording

- Click the Start Recording option in the Performance Analyzer pane.
- This will start capturing the performance information of the dashboard visuals.
Step 4: Refresh Dashboard Visuals

- Click Refresh visuals in the Performance Analyzer pane.
- Allow all dashboard visuals to refresh.
- Observe the execution time recorded for each visual.
Step 5: Analyze Performance Results

- Review the recorded performance information for individual visuals.
- Identify which visuals take more time to load.
- Compare the execution times to understand dashboard performance.
Expected Outcome:
Successfully analyze the loading performance of the Power BI dashboard and identify visuals that may require performance optimization.

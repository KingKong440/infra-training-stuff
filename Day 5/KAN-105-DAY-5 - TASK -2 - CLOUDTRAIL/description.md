Task Title: Configure S3 Bucket Monitoring Using AWS CloudTrail

Description:

Set up monitoring for an AWS S3 bucket using AWS CloudTrail to track bucket-related activities and identify important events.

Tasks:

- Create or configure an S3 bucket.
- Enable CloudTrail logging to capture relevant S3 API activity.
- Monitor events such as object uploads, deletions, and bucket configuration changes.
- Verify that CloudTrail logs are delivered to the configured destination.
- Document the monitoring configuration and validation results.
Acceptance Criteria:

- S3 activity is recorded in CloudTrail.
- Relevant events can be identified and reviewed.
- Logging is validated successfully.
Deliverable: A working S3 and CloudTrail monitoring configuration with documented test results.

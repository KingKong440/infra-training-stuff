## Description

Execute 10 Linux commands to inspect system resources, analyze processes, manage storage, and investigate system activity.

Tasks

- htop — Inspect running processes and resource utilization.
- du -sh * — Analyze disk usage of files and directories.
- df -h — Inspect filesystem space utilization.
- free -h — Check memory and swap usage.
- lsblk — Inspect block devices and partitions.
- find /var/log -type f — Locate log files.
- journalctl -p err -b — Inspect errors from the current boot.
- ss -tulpn — Inspect listening ports and associated processes.
- ps aux --sort=-%mem | head — Identify processes consuming the most memory.
- lsof -i — Inspect processes using network sockets.

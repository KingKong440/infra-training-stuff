## Description

Provision an AWS EC2 instance using Amazon Linux and install Jenkins by following the official Jenkins installation documentation.

Reference: https://www.jenkins.io/download/ 

Tasks

- Launch an EC2 instance with the specified operating system.
- Configure the required security group rules and network access.
- Connect to the instance using SSH.
- Install the required dependencies for Jenkins.
- Install and configure Jenkins using the official documentation.
- Enable Jenkins to start automatically on system boot.
- Verify that the Jenkins service is running.
- Access the Jenkins web interface and complete the initial setup.
Acceptance Criteria

- The EC2 instance is running with the specified operating system.
- Jenkins is installed and running successfully.
- Jenkins starts automatically after a system reboot.
- The Jenkins web interface is accessible through the configured network.
- Initial Jenkins setup is completed successfully.
Reference

- Jenkins official installation guide: https://www.jenkins.io/download/

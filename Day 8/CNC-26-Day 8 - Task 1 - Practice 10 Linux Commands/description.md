## Description

Objective

Practice 10 useful Linux commands beyond the basics and understand their common options through hands-on exercises.

Commands to Practice

1. find — Find files and directories by name, type, or size.
2. grep — Search for patterns in files.
3. awk — Extract and process columns of text.
4. sed — Search and replace text.
5. xargs — Pass input from one command as arguments to another.
6. chmod — Change file permissions.
7. chown — Change file ownership.
8. tar — Create and extract archives.
9. ps — Inspect running processes.
10. ss — Inspect listening ports and network connections.
